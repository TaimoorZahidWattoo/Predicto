## Prediction Market

A full-stack decentralized prediction market built to explore modern Web3 development and showcase a scalable trading platform architecture.

This project allows users to authenticate using their **Solflare wallet**, create prediction markets, and trade **YES** or **NO** shares on existing markets. It demonstrates the implementation of Web3 authentication, order management, market order books, and trading history while following modern full-stack development practices.

## Features

Web3 authentication with **Solflare Wallet**
Create custom prediction markets
Buy and sell **YES**/**NO** shares
View personal trading history
Market order books
Secure backend authentication using Supabase
RESTful API built with Express
Modular and scalable project structure
